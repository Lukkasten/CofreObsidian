# Agente de IA como serviço no WhatsApp

Você é um especialista em automação, inteligência artificial, vendas e atendimento ao cliente. Quero criar um Agente de IA (tipo chatbot inteligente) para atender empresas pelo WhatsApp. Esse agente deve ser configurado com ChatGPT, usando ferramentas como N8N, Twilio, Z-API ou plataformas de chatbot, e funcionar como um serviço que eu posso vender para clientes locais ou digitais.

Me entregue o seguinte:

✅ 1. Proposta de Serviço
- Sugira 3 tipos de negócios ideais para oferecer esse agente (ex: clínica, loja de roupa, infoprodutor, estética, delivery, consultoria)
- Crie um pitch simples para oferecer esse serviço (ex: "Você já imaginou ter uma IA atendendo seus clientes 24h por dia e ainda vendendo por você no automático?")
- Mostre o que eu posso prometer de resultado (ex: mais vendas, captação de leads, agendamento de consultas, etc.)

✅ 2. Estrutura do Agente de IA
- Crie um modelo de fluxo de atendimento (boas-vindas, perguntas frequentes, direcionamento para venda ou agendamento)
- Sugira uma personalidade para o bot (tom de voz, estilo de resposta)
- Liste as principais funções que esse agente pode cumprir:
  - Captar leads - Responder dúvidas - Agendar horários
  - Repassar contatos pro time - Vender no automático com copy persuasiva

✅ 3. Configuração Técnica
- Dê sugestões de plataformas para integrar com o WhatsApp (ex: Z-API, Twilio, N8N + ChatGPT API)
- Mostre um exemplo de integração simples com N8N ou outra ferramenta acessível
- Explique como posso conectar isso a uma planilha, CRM ou sistema de agendamento

✅ 4. Entregáveis para o Cliente
- Crie uma lista de o que será entregue no serviço (ex: setup completo, treinamento, painel de respostas, manutenção semanal)
- Sugira 3 planos de preço (ex: R$197, R$297, R$497/mês) com o que cada um inclui
- Crie uma proposta comercial resumida em linguagem persuasiva, como se fosse para um PDF ou landing page

✅ 5. Estratégia de Venda
- Me dê uma sequência de 3 stories + 1 post pra vender esse serviço no Instagram
- Crie um CTA pra usar em direct, bio ou WhatsApp
- Sugira formas de captar os primeiros 5 clientes rapidamente

Use linguagem clara, persuasiva e com foco prático.
Aja como meu parceiro estratégico.
Quero sair desse prompt com tudo pronto pra vender esse serviço ainda hoje.
